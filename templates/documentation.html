Documentation

Complete guide to using the Depression Risk Screening tool, including the web interface and API.

Web Interface

The web interface provides a form-based assessment with the following sections:

  1. Demographics — Enter your gender, age, city, and profession.
  2. Academic & Work — Provide your degree, CGPA, pressure levels, satisfaction ratings, and work/study hours.
  3. Lifestyle & Health History — Report sleep duration, dietary habits, financial stress, suicidal ideation history, and family mental health history.

After completing all fields, click "Run Screening" to generate the risk assessment. Results are displayed with a probability score, risk level classification, and personalized recommendations.

API Reference

The tool exposes a REST API endpoint for programmatic access:

POST /api/predict

Submit a JSON payload with all 16 required features. Returns a prediction result with probability scores.

Request body (JSON):

{
  // Required fields
  "Gender": 1,
  "Age": 22,
  "City": "Karachi",
  "Profession": "Student",
  "Academic Pressure": 3,
  "Work Pressure": 2,
  "CGPA": 3.2,
  "Study Satisfaction": 3,
  "Job Satisfaction": 3,
  "Sleep Duration": "7-8 hours",
  "Dietary Habits": "Healthy",
  "Degree": "BSc Computer Science",
  "Have you ever had suicidal thoughts ?": 0,
  "Work/Study Hours": 6,
  "Financial Stress": 2,
  "Family History of Mental Illness": 0
}

Response (JSON):

{
  "prediction": 0,
  "depression_probability": 0.0234,
  "no_depression_probability": 0.9766
}

Example using curl:

curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"Gender":1,"Age":22,"City":"Karachi","Profession":"Student",
    "Academic Pressure":3,"Work Pressure":2,"CGPA":3.2,
    "Study Satisfaction":3,"Job Satisfaction":3,
    "Sleep Duration":"7-8 hours","Dietary Habits":"Healthy",
    "Degree":"BSc","Have you ever had suicidal thoughts ?":0,
    "Work/Study Hours":6,"Financial Stress":2,
    "Family History of Mental Illness":0}'

Validation & Error Handling

The web interface performs client-side validation before submission. The server also validates all inputs:

  • ✓ Required fields are checked for presence
  • ✓ Numeric fields are validated for type and range
  • ✓ Feature engineering is applied automatically
  • ✓ Errors return descriptive messages on the result page
  • ✓ API errors return HTTP 400 with JSON error detail
